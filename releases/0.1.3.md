# v0.1.3 — @focus-labs/fault-client

Date : 29 septembre 2026

## Résumé

Le paquet est désormais publié en **JavaScript ESM** avec un fichier de types `index.d.ts` écrit à la main, sans étape de build. Il est utilisable depuis un projet ESM (`import`) et depuis un projet CommonJS (`require`) sur Node >= 20.19.

## Problème corrigé

Dans la `0.1.2`, le paquet était déclaré `"type": "module"` mais ne publiait que du TypeScript (`src` et `index.ts`), alors que `main` pointait vers `src/index.js`. Résultat : aucun fichier JavaScript n'était importable, ni en ESM ni en CommonJS (erreur TS1479 côté Nexus-Back).

## Changements

- Le client est réécrit en JavaScript ESM (`src/client.js`, `index.js`).
- Ajout de `index.d.ts` avec les types : `FaultApiClient`, `FaultApiClientOptions`, `RevealFolderResult`, `RevealSecretResult`, `RevealPathResult`.
- `package.json` : `main` → `index.js`, `types` → `index.d.ts`, ajout de `exports`, `files` → `src`, `index.js`, `index.d.ts`, `engines.node` >= 20.19.
- Suppression des sources TypeScript (`client.ts`, `types.ts`, `index.ts`) du paquet.
- Ajout d'un `tsconfig.json` (vérification de types et ESLint uniquement, aucun build).

## API

Aucun changement d'API : `FaultApiClient`, `setPersonalToken`, `revealByPath` et `getSecrets` se comportent comme avant.

## Utilisation

ESM / TypeScript :

```ts
import { FaultApiClient } from '@focus-labs/fault-client'

const client = new FaultApiClient({
  baseURL: 'http://localhost:3000/api',
  token: 'smtk_xxxxxxxx...',
  personalToken: 'smtk_xxxxxxxx...'
})

const secrets = await client.getSecrets('Test')
```

CommonJS (Node >= 20.19 ou >= 22.12) :

```js
const { FaultApiClient } = require('@focus-labs/fault-client')
```

En TypeScript, un projet CommonJS doit utiliser TypeScript >= 5.8 avec `"module": "nodenext"` pour que `require()` d'un module ESM ne soit plus signalé (TS1479).

## Migration

```bash
npm i @focus-labs/fault-client@0.1.3
```

La version `0.1.2` est non importable et peut être dépréciée :

```bash
npm deprecate @focus-labs/fault-client@0.1.2 "Non importable (TypeScript ESM uniquement). Utiliser >=0.1.3"
```

## Note de maintenance

Les types sont écrits à la main dans `index.d.ts` : toute modification de signature dans `src/client.js` doit être reportée dans ce fichier.
