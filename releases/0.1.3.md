# v0.1.3 — @focus-labs/fault-client

Date : 29 septembre 2026

## Résumé

Le paquet est désormais publié en **JavaScript CommonJS** avec un fichier de types `index.d.ts`, comme `sql-connector`. Il est utilisable à la fois depuis un projet CommonJS (`require`) et depuis un projet ESM (`import`), sans étape de build.

## Problème corrigé

Dans la `0.1.2`, le paquet était déclaré `"type": "module"` et ne publiait que du TypeScript (`src` et `index.ts`), alors que `main` pointait vers `src/index.js`. Résultat :

- un projet CommonJS (ex. Nexus-Back) ne pouvait pas l'importer : `TS1479 — the referenced file is an ECMAScript module and cannot be imported with 'require'` ;
- même en ESM, l'import échouait, car aucun fichier `.js` n'était publié.

## Changements

- Le code du client est réécrit en JavaScript CommonJS (`src/client.js`, `index.js`).
- Ajout de `index.d.ts` avec les types : `FaultApiClient`, `FaultApiClientOptions`, `RevealFolderResult`, `RevealSecretResult`, `RevealPathResult`.
- `package.json` :
  - suppression de `"type": "module"` ;
  - `main` → `index.js`, ajout de `types` → `index.d.ts` ;
  - `files` → `src`, `index.js`, `index.d.ts`.
- Suppression des sources TypeScript (`client.ts`, `types.ts`, `index.ts`) et de `tsconfig.json` du paquet.

## API

Aucun changement d'API : `FaultApiClient`, `setPersonalToken`, `revealByPath` et `getSecrets` se comportent comme avant.

## Utilisation

CommonJS :

```js
const { FaultApiClient } = require('@focus-labs/fault-client')
```

ESM / TypeScript :

```ts
import { FaultApiClient } from '@focus-labs/fault-client'

const client = new FaultApiClient({
  baseURL: 'http://localhost:3000/api',
  token: 'smtk_xxxxxxxx...',
  personalToken: 'smtk_xxxxxxxx...'
})

const secrets = await client.getSecrets('Test')
```

## Migration

```bash
npm i @focus-labs/fault-client@0.1.3
```

Aucune modification de code n'est nécessaire côté consommateur. La version `0.1.2` est non importable et peut être dépréciée :

```bash
npm deprecate @focus-labs/fault-client@0.1.2 "Non importable (TypeScript ESM uniquement). Utiliser >=0.1.3"
```

## Note de maintenance

Les types sont écrits à la main dans `index.d.ts` : toute modification de signature dans `src/client.js` doit être reportée dans ce fichier.
