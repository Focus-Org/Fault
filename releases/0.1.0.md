# @fault/api-client v0.1.0

Première version du client Node.js/TypeScript (Axios) pour l'API FAULT.

## Ajouté

- **`FaultApiClient`** : client Axios pour l'API FAULT.
  - `revealByPath(path)` — appelle `POST /secrets/reveal` avec
    `Authorization: Bearer <PAT>` et, si configuré, `X-Personal-Token`
    (seule route de l'API utilisable avec un Personal Access Token).
  - `getSecrets(path)` — résout un dossier et récupère la valeur de
    chacun de ses secrets ; renvoie une `string` si `path` désigne
    directement un secret, ou un objet `{ [key_name]: value }` sinon.
  - `setPersonalToken(token)` pour changer le `X-Personal-Token` après
    coup.
  - Erreurs HTTP normalisées en `Error` avec le message renvoyé par
    l'API (`error`/`message` du corps de réponse).
- Types exportés : `RevealPathResult`, `RevealFolderResult`,
  `RevealSecretResult`, `FaultApiClientOptions`.
- Tests unitaires (Vitest) couvrant `revealByPath`, `getSecrets` et la
  gestion des erreurs, avec `axios` mocké.
- Configuration ESLint (flat config) avec `typescript-eslint` et
  `eslint-plugin-security`.
- `examples/reveal.ts` — exemple exécutable équivalent à l'appel curl
  historique.

## Installation

```bash
npm install @fault/api-client
```

## Utilisation

```ts
import { FaultApiClient } from '@fault/api-client'

const client = new FaultApiClient({
  baseURL: 'http://localhost:3000/api',
  token: 'smtk_...',
  personalToken: 'smtk_...'
})

const secrets = await client.getSecrets('test')
```
